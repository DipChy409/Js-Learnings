String Methods and Properties

Before starting string methods and properties we need know that strings are indexed. So basically we can access any single character of a string by doing something like this.

Expression: 'Hello World'[1]

Result: 'e'

There is only one property that exists.

Property

  • length

Methods (Without Argument)

  • toUpperCase()
  • toLowerCase()
  • trim()
  • trimStart()
  • trimEnd()

Methods (With Argument)

  • includes(): it means to check if a string contains a specific substring
  • indexOf(): it means to find the position of a specific character or substring
  • replace(): it means to replace a specific substring with another substring
  • replaceAll(): it means to replace all occurrences of a specific substring with another substring
  • concat(): it means to join two or more strings
  • padStart(): it means to pad the beginning of a string with another string
  • padEnd(): it means to pad the end of a string with another string
  • charAt(): it means to get the character at a specific position
  • charCodeAt(): it means to get the Unicode value of the character at a specific position
  • slice(): it means to extract a portion of a string.like: "Hello World".slice(0, 5)
  • split(): it means to split a string into an array of substrings
  • startsWith(): it means to check if a string starts with a specific substring
  • endsWith(): it means to check if a string ends with a specific substring
  • search(): it means to search for a specific substring in a string
  • at(): it means to get the character at a specific position (negative index allowed)
  • repeat(): it means to repeat a string a specific number of times.like: "hello".repeat(3);
  • localeCompare(): it means to compare two strings based on the locale.Useful for sorting array(contains: "string" Elements)
