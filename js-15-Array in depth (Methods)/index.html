(Q. in Interview):What is the difference between arr.slice() and arr.splice()? 

    Answer:
The primary difference between slice and splice in JavaScript is that slice creates a new array from a portion of an existing one without changing the original, while splice modifies the original array by adding, removing, or replacing elements.
