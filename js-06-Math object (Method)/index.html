JavaScript primarily uses two sets of equality operators: loose and strict.

  1. Strict Equality (=== and !==)
    2. They compare both the value and the data type without any automatic conversion

    • === (Strict Equal): Returns true only if both operands have the same type and the same value.

      • 5 === 5 → true
      • 5 === '5' → false (different types: number vs string)
    • !== (Strict Not Equal): Returns true if the operands are of different types or have different values.
    • 5 !== '5' → true
  2. Loose Equality (== and !=)
These operators perform type coercion (automatic conversion) before comparing the values.
  1. == (Loose Equal): Attempts to convert operands to a common type and then compares them.
    • 5 == '5' → true (string '5' is converted to number 5)
    • 0 == false → true (false is converted to 0)
    • null == undefined → true (special rule)
  2. != (Loose Not Equal): Returns true if the values are not equal after type coercion.
    • 5 != '5' → false
