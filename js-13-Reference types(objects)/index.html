Javascript Data Types

There are several data types in javascript:

  1. Non primitive(Reference Types)
  2. Primitive (Value Types)

In this lesson we will learn primitive data types

We can classify primitive data types as follows:

  1. Number
  2. String
  3. Boolean
  4. Undefined
  5. Null
  6. BigInt
  7. Symbol

Non Primitive data types

There is only one type of non primitive data type that is called OBJECT.

Objects is further divided into 3 categories

  1. Object Literals
  2. Arrays
  3. Functions

The Object type is used to store collections of data and more complex entities

Creating an Object.... You can create objects using two main methods: Literal Notation: let person = { name: "Alice", age: 25 };. Constructor Method: let person = new Object();
