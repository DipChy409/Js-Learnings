What are Variables?

A javascript variable is a container for storing data values.

And we can store different types of data in variables, such as numbers, strings, and boolean values.

  • Using the var keyword
  • Using the let keyword
  • Using the const keyword

Rules for naming variables

A variable name can contain letters, digits, underscores, and dollar signs but must not start with a digit.

  • capital Letter: A to z
  • Small lettter : a to z
  • Digit(0-9) but we cannot start variable with a digit
  • only 2 special characters: _ and $
